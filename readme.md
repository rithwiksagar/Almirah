# ALMIRAH - A Smart Way To Store Content
ALMIRAH is a simple and intuitive link-storage web application designed to help you save, organize, and revisit any kind of link you come across on the internet. Whether it's articles, videos, resources, or tools—ALMIRAH works as your personal digital cupboard where everything stays neatly stored and easy to access.

**Note**: This project is currently under development. Some features may be incomplete.Deployment will follow once the project gets finished.

## Features
* Save any link with title & description

* Categorize and organize saved links

* Minimal and clean UI

* Edit & delete saved links

* Personal dashboard

* content sharing 

## Tech Stack
* __Frontend__ : React 18(downgraded it just to use recoil), TypeScript
* __Backend__ : Node.js, Express.js, MongoDB
* __Authentication__ : JWT
* __Styling__ : Tailwind CSS

## Setup & Installation

**Note** : Make sure your project uses React 18
#### Clone the repo
```bash
git clone https://github.com/rithwiksagar/almirah.git
```
#### Navigate
```bash
cd almirah
```
#### Navigate between Frontend and Backend
```bash
cd almirah-Frontend
cd almirah-Backend
```

#### Install dependencies
```bash
npm install
```

#### Start development
```bash
npm run dev
```
